# 笔记整理约定

[[Dashboard|返回首页]]

## 从首页开始

把 [[Dashboard|科研首页]] 作为日常入口。各分类目录提供标题清晰的链接；不必靠文件树里的引用键寻找论文。

## 每类内容只放一处

- 临时材料 → 00_Inbox，整理后移动到对应分类。
- 一篇论文 → 10_Literature；Zotero 自动生成的文件名保留引用键。
- 研究目标、任务、会议与方案 → 20_Projects / 课题名称。
- 一次实际实验 → 30_Experiments，建议命名为“YYYY-MM-DD 实验主题”。
- 一个可复用概念 → 40_Knowledge，用概念本身命名。
- 操作说明 → 80_Guides；模板 → 90_Templates；预置示例 → 95_Examples。
- 图片 → 99_Attachments；临时诊断材料存于隐藏的 .maintenance，不进入日常阅读与 Git 同步。

## 保持笔记简短

正文先放自己的总结，再放原文摘录。摘要和备用批注默认折叠。标题以中文为主，必要术语保留英文，不重复给每个小节加英文翻译。

文献显示名称可以改，citekey 文件名及 Zotero 链接保持稳定。生成笔记的手写内容放在 persist 保留区；不要删除隐藏的 begin/end 和 Import Date 标记。

## 本次整理做了什么

新增首页与分类目录；把完整联动说明迁入本目录；将 RCAN 和 Baseline 预置记录移入示例区；保留正式论文及原始批注，折叠可能重复的 PDF 摘录；精简新笔记模板。

旧入口 README、Dashboard 和模板文件路径仍可使用。整理前备份单独保存在本机，不混入日常笔记库。
