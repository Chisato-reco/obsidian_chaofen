# 科研知识库工作流与 Obsidian 必会操作

[[Dashboard|返回科研首页]] · [[80_Guides/Obsidian与Zotero使用指南|Zotero 联动说明]] · [[90_Templates/模板索引|模板索引]]

本手册的目标不是把所有资料搬进 Obsidian，而是让每次阅读都能留下可追溯的理解，并能从研究问题找到依据、方法、实验和结论。

## 一、先分清三个工具

| 工具 | 负责什么 | 内容放在哪里 |
| --- | --- | --- |
| Zotero | 文献条目、PDF、原文批注、引用键、参考文献导出 | Zotero 文献库和附件 |
| Obsidian | 个人理解、概念、研究问题、项目计划、实验记录和 Markdown 链接 | 本知识库 |
| GitHub | 笔记的版本历史和仓库备份 | `Chisato-reco/obsidian_chaofen` |

Zotero 标注被导入，只代表摘录有了可搜索的落脚点；**知识卡片应写自己的解释、出处、适用条件和与课题的联系。** Zotero 文献同步、Obsidian 笔记同步、PDF 附件同步是三件独立的事。

## 二、一次完整的文献到实验流程

### 1. 收集与筛选

1. 在 Zotero Connector 保存论文，确认标题、作者、年份、DOI 和 PDF 没有错。
2. 将论文放入 Zotero 的课题分类，例如“电镜超分 / 退化建模”或“电镜超分 / 重建方法”；分类可多选，不要靠目录名承载所有信息。
3. 确认 Better BibTeX 已给论文分配 citekey。citekey 是稳定机器标识，用于导入文件名和引用；**不要为了好看频繁修改**。
4. 快速筛选时，只写这篇论文与哪个研究问题有关，以及是否值得精读。无需每篇都做长笔记。

### 2. 在 Zotero 阅读和标注

在 PDF 里围绕证据做少量、有目的的批注：

| 颜色 | 本库约定 | 适合标什么 |
| --- | --- | --- |
| 黄 | 背景与概念 | 问题定义、关键事实、必要理论 |
| 绿 | 方法与创新 | 模型、算法、实验设计、贡献 |
| 蓝 | 结果与证据 | 定量结果、图表、对照实验 |
| 红 | 局限与疑问 | 假设限制、失败条件、未解决问题 |

在 Zotero 的批注 comment 写自己的短问题，例如“这项结论是否只对晶体样品成立？”把**原文摘录**和**自己的判断**分开。要引用图表时用区域批注，并记下图号及它支持的结论。

### 3. 导入 Obsidian 文献笔记

1. 保持 Zotero 运行，在 Obsidian 按 `Ctrl+P`，运行 **Zotero Integration: Create Literature Note**。
2. 搜索标题或作者，选择论文的父条目，生成 `10_Literature/<citekey>.md`。
3. 检查摘要、期刊、年份、DOI、PDF 和批注链接；点“查看原文”确认能回到 Zotero PDF 对应页。
4. 在“阅读总结”保留区完成下一节的三问。只需重读时才补充批注；不用把整篇文章搬进笔记。
5. 更新 Zotero 标注后重新导入。模板会刷新自动生成部分；自己的文字只写在 `research-summary` 或 `notes` 保留区。不要删掉 `%% begin ... %%`、`%% end ... %%` 和末尾 Import Date 标记。

### 4. 把论文变成自己的知识

每篇值得精读的论文，至少回答：

1. **问题**：作者要解决什么问题？为什么已有方法不够？
2. **方法**：核心假设、数据、模型或算法分别是什么？
3. **证据**：哪张图、哪张表或哪组对照支持结论？是否有反例或边界？
4. **迁移**：它对电镜超分有什么启发？数据条件、噪声、成像物理和评价指标是否相同？
5. **下一步**：提出一个可检验的问题，而不是直接把“可以尝试”当作结论。

当一个术语或方法在多篇论文、项目和实验中反复出现时，再建立一篇 `40_Knowledge` 知识卡片。卡片写定义、直觉、适用条件、常见误用、证据来源，并链接到相关论文。若只是单篇论文中的背景介绍，留在文献笔记里即可。

### 5. 从知识回到研究任务

在 [[20_Projects/电镜超分/项目总览|项目总览]] 维护少量当前问题和下一步任务。每个待办尽可能写成可检查动作，例如：

> 对同一批留出图像比较 bicubic 与实测 PSF 退化，记录 PSNR、SSIM 和 FRC；确认两种退化设置及数据划分后再决定训练基线。

任务引用依据论文、概念卡片或已有实验。不要把多个方向塞进一条巨大待办；一条只对应一个明确结果。

### 6. 计划、运行并记录实验

1. **运行前**：在 `30_Experiments` 新建记录，写假设、相对基线的唯一改动、数据版本/划分、环境、代码 commit、配置和随机种子。
2. **运行中**：记录实际命令、失败、重试和异常，不只记最终最好的一次。
3. **运行后**：把 PSNR、SSIM、FRC 等与评价实现、单位、数据条件一起记录；贴日志、输出或图表路径。
4. **得出结论**：说明证据支持什么、还不能说明什么、可能混杂因素是什么，并链接回项目问题和相关论文。
5. 不要把模板里的示例数字当实际结果；新模板使用“待测”，只填真正运行过的数据。

### 7. 每周回顾与维护

- 清理 `00_Inbox`：归档、建立链接或删除重复临时内容。
- 项目页只保留当前目标、阻塞点和下一步；完成项移入对应实验或阶段总结。
- 从实验结果反向检查：是否需要新概念卡片、补读论文或修正假设？
- 检查 GitHub 同步成功。Git 备份笔记，不替代 Zotero 文献和 PDF 的同步。

## 三、Obsidian 必会操作

### 1. 双链：知识网络的基本语法

在编辑器输入 `[[` 搜索并选择现有笔记。推荐用显示文字，让链接对人可读：

```markdown
[[40_Knowledge/傅里叶环相关|傅里叶环相关（FRC）]]
[[10_Literature/chenElectronPtychographyAchieves2021|Chen 等（2021）]]
[[20_Projects/电镜超分/项目总览#技术路线与关键模块|项目技术路线]]
```

`[[笔记名]]` 链到整篇笔记；`[[笔记名#标题]]` 链到标题；`[[笔记名#^块标识]]` 链到一段文字。悬停可预览，点击进入。移动或重命名笔记时，开启的自动更新链接会改写库内链接。

优先链接有后续价值的**概念、问题、方法、论文和实验**。不必给每个普通词都加链接；只有真正能从上下文跳过去并继续工作的链接才有用。

### 2. 出链、反向链接与关系检查

- **出链**：当前笔记引用了什么。文献页应链接相关概念和项目；实验页应链接研究问题、方法和依据。
- **反向链接**：哪些笔记提到了当前笔记。查看某个方法卡片的反向链接，能发现哪些论文和实验用过它。
- **未链接提及**：Obsidian 发现了同名词但尚未建立链接时，可判断是否值得连接。相同术语不一定表示相同概念，先看上下文。

打开右侧“出链”或“反向链接”面板；可把常用核心面板固定在侧栏。

### 3. 搜索与快速切换

- `Ctrl+O` 快速切换笔记：输入概念、作者、实验主题，比逐层点目录快。
- `Ctrl+Shift+F` 全库搜索：找术语、citekey、实验命令或 DOI；必要时限制路径或标签。
- `Ctrl+P` 命令面板：搜索创建文献笔记、插入模板、切换预览、Git 操作等命令。
- 查找 Zotero 原文：在全库搜索 citekey 或 DOI，再从文献笔记的 Zotero / PDF 链接打开原文。

### 4. 属性和标签：结构化筛选

**属性**放少数稳定字段，例如 `citekey`、`year`、`status`、`model_type`、`dataset`。用于排序、筛选和 Dataview。值尽量统一：年份用数字，日期用 ISO 格式；状态选一套固定词汇。

**标签**用于横跨文件夹的主题或工作状态，例如 `#literature/review`、`#method/degradation`、`#status/to-read`。先从现有词汇选，避免同义标签并存，例如“超分”“超分辨率”“SR”三套都用。文件夹回答“这是什么类型的记录”，标签回答“它属于哪些横切主题”；不要复制一整套目录层级做标签。

不确定是否需要新标签时先加双链。双链能指向一篇有定义、说明和关系的中心笔记；标签只是筛选词。

### 5. 模板、属性视图与 Dataview

- 用 [[90_Templates/模板索引|模板索引]]选择文献、实验或概念模板。
- Zotero 文献模板由 Zotero Integration 读取，**不要用 Templater 插入或渲染它**。
- Templater 用于手动新建实验、概念或速读笔记，并填入日期等动态字段。
- Dataview 可用统一属性自动生成文献、实验和概念清单。若表格为空，先核对笔记的 frontmatter 属性名称和所在目录，再检查 Dataview 插件是否启用。
- 如果只是轻量浏览，可以用 Obsidian 核心属性视图或 Bases；不要为了仪表盘给每篇笔记增加大量没人维护的字段。

### 6. 折叠、嵌入与图表

- 点击标题左侧箭头折叠大纲；摘要、长引用、原始批注适合折叠，自己的结论应直接可见。
- `![[笔记#标题]]` 可以嵌入另一篇笔记的一个章节；首页已经嵌入项目任务清单。
- `![[99_Attachments/图像.png]]` 在笔记中显示图像。图像应放库内附件目录，并在旁边说明来源、图号和观察结论。
- Canvas 适合少数需要空间布局的复杂问题，如“退化因素→算法→评价指标”路线图；Canvas 不替代可搜索的普通 Markdown 笔记。
- Graph View 用来发现连接稀疏或孤立的笔记，不是知识质量指标。笔记很多但链接没有明确含义，图谱也不会自动形成知识体系。

### 7. 阅读模式与修改

阅读时在阅读视图和编辑视图之间切换；在阅读视图长按或点击词语，可使用快速预览和链接导航。文件列表适合分类浏览，命令面板和全库搜索适合日常定位。首页、文献目录、项目总览和实验目录已经加入书签，可从左侧书签面板打开。

## 四、建议掌握顺序

先掌握这些基础操作，再逐步扩展：

1. `[[双链]]`、标题链接、搜索、快速切换和反向链接。
2. 按 Zotero 模板导入一篇文献，并亲手写完“问题—方法—证据—迁移”。
3. 新建一张概念卡片，把它链接到至少两篇支持或讨论该概念的文献。
4. 用实验模板记录一次真实运行，再从实验页链接回项目问题。
5. 统一少量属性和标签，用 Dataview 自动查看未读文献与最近实验。
6. 每周回顾项目待办、孤立笔记、链接和 GitHub 同步状态。

核心验收不是图谱有多少节点，而是随机打开一个研究问题时，能沿链接找到相关论文和页码、知识概念、实验条件与结论，并能说明证据的边界。

## 五、一篇论文的精读验收单

- [ ] Zotero 条目信息和 PDF 正确，citekey 稳定。
- [ ] Obsidian 笔记能跳回条目和具体批注页。
- [ ] 我能用自己的话写出问题、方法、证据与局限。
- [ ] 关键判断有论文页码、图表或实验记录作为依据。
- [ ] 文献笔记至少连接到一个研究问题或概念；如果没有实际关联，不为凑数量强行建链。
- [ ] 若形成可复用认识，已建立概念卡片并关联来源。
- [ ] 总结和个人想法写在 Zotero 再导入仍会保留的位置。

## 六、你可以立刻完成的 30 分钟练习

1. 打开 [[10_Literature/chenElectronPtychographyAchieves2021|Chen 等（2021）文献笔记]]，从一个批注链接回 Zotero 检查页码。
2. 在“阅读总结”保留区用自己的话回答：这篇论文主要解决什么成像问题？它是否直接研究深度学习超分？
3. 打开 [[40_Knowledge/电镜超分辨率基础与FRC评价|FRC 知识卡片]]，补上一个来源链接和适用条件。
4. 在文献笔记中用 `[[...]]` 链接到该知识卡片及 [[20_Projects/电镜超分/项目总览|当前课题]]。
5. 从项目页点反向链接，确认刚才建立的连接能让你回到论文。

若该论文与 FRC 或当前课题并无直接证据关系，不要为了完成练习而写成论文结论；可以在“个人想法”里明确标注为待验证假设。
